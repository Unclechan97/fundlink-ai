## 2. 意图识别 + 拆分确认

```
┌─────────────────────────────────────────────────────────┐
│ 🔍 AI 识别结果                                          │
│ ┌───────────────────────────────────────────────────┐   │
│ │ 意图: 接口开发          置信度: 95%                │   │
│ │ → 检测到 3 个接口定义                              │   │
│ └───────────────────────────────────────────────────┘   │
│                                                         │
│ 检测到的接口:                            [全选] [取消]  │
│ ┌───────────────────────────────────────────────────┐   │
│ │ ☑ 1. 放款申请     POST /api/loan/apply    LOAN   │   │
│ │ ☑ 2. 放款查询     POST /api/loan/query    LOAN   │   │
│ │ ☑ 3. 还款申请     POST /api/repay/apply   REPAY  │   │
│ └───────────────────────────────────────────────────┘   │
│                                                         │
│ ⚠ 去重提示: "放款申请"和"放款申请接口"已合并             │
│                                                         │
│ [不是接口文档？切换为: 知识问答 | 问题排查]               │
│ [手动逐个处理]  [自动闭环全部]                           │
└─────────────────────────────────────────────────────────┘
```

**交互要点：**
- 用户可勾选/取消勾选接口
- 去重提示可展开查看被合并的原始文本
- 低置信度（< 0.7）时弹确认框
- 意图误判时可一键切换

## 3. 自动模式 — 并行处理进度

```
┌─────────────────────────────────────────────────────────┐
│ 🔄 自动闭环    Task: LOOP-A1B2C3D4    3 个接口并行中    │
├─────────────────────────────────────────────────────────┤
│  ┌──────────────┐  ┌──────────────┐  ┌──────────────┐   │
│  │ 📋 放款申请   │  │ 📋 放款查询   │  │ 📋 还款申请   │   │
│  │ ✅ 已完成     │  │ 🔄 处理中     │  │ ⏳ 等待中     │   │
│  │ ANALYZE ✓   │  │ ANALYZE ✓   │  │ ANALYZE ⏳  │   │
│  │ VALIDATE ✓  │  │ VALIDATE 🔄 │  │ VALIDATE ⏳  │   │
│  │ DRYRUN ✓    │  │ DRYRUN ⏳   │  │ DRYRUN ⏳   │   │
│  │ 写入 ✓      │  │              │  │              │   │
│  └──────────────┘  └──────────────┘  └──────────────┘   │
│                                                         │
│  ┌──────────────────────────────────────────────────┐   │
│  │ 🔴 还款申请 - ANALYZE 失败: LLM 解析错误          │   │
│  │ [重试此接口]  [跳过]  [编辑后重试]                 │   │
│  └──────────────────────────────────────────────────┘   │
│                                                         │
│  [中断全部任务]                                         │
└─────────────────────────────────────────────────────────┘
```

**交互要点：**
- 每个接口一张卡片，实时显示阶段状态
- 卡片点击可展开详细日志（复用现有 Collapse 组件）
- 失败接口有独立操作按钮（重试 / 跳过 / 编辑）
- SSE 事件按 `interfaceId` 路由到对应卡片

## 4. 手动模式 — 逐个查看

```
┌─────────────────────────────────────────────────────────┐
│ 接口列表    [全部解析]  [全部采纳]  [写入 FundLink]      │
├─────────────────────────────────────────────────────────┤
│ ▼ 1. 放款申请  POST /api/loan/apply  [✅ 已解析]       │
│   ┌─ 字段映射表（现有 UI 复用）──────┐                 │
│   └─ 流程图（ReactFlow 复用）────────┘                 │
│                                                         │
│ ▼ 2. 放款查询  POST /api/loan/query  [⚠ 部分字段无匹配] │
│   ┌─ 字段映射表─────────────────────┐                 │
│   └─ 流程图────────────────────────┘                 │
│                                                         │
│ ▶ 3. 还款申请  POST /api/repay/apply  [⏳ 待解析]       │
└─────────────────────────────────────────────────────────┘
```

**交互要点：**
- Collapse 折叠面板，每项展开后复用现有的字段映射表 + ReactFlow 流程编辑器
- "全部解析"一键触发所有未解析接口
- "全部采纳"一键采纳所有字段映射
- "写入 FundLink"逐个写入（成功/失败独立展示）

## 7. 状态管理

```javascript
// 多接口状态结构
{
  mode: 'manual' | 'auto',
  intent: { type: 'INTERFACE_DEV', confidence: 0.95 },
  interfaces: [
    {
      interfaceId: 'loanApply_a1b2c3',
      name: '放款申请',
      endpoint: 'POST /api/loan/apply',
      selected: true,              // 用户勾选
      status: 'SUCCESS' | 'FAILED' | 'TIMEOUT' | 'PENDING',
      result: { /* RequirementResult */ },
      // 自动模式特有
      phases: {
        ANALYZE: { status: 'done', messages: [...] },
        VALIDATE: { status: 'active', messages: [...] },
        DRYRUN: { status: 'pending', messages: [...] },
      }
    }
  ],
  totalCount: 3,
  successCount: 2,
  failedCount: 1
}
```

前端用 `useReducer` 管理（复用 AutoLoopPanel 的模式），按 `interfaceId` 更新对应接口的状态。
